# Somalia Space Program

## 可玩战斗 MVP

Godot 4.7.2 工程位于 `godot/`。首次打开先运行 `godot --headless --path godot --editor --import`。运行：`godot --path godot`。无界面机制自检：`godot --headless --path godot --script res://check.gd`。

主菜单包含海盗遭遇、潜行突围任务和其他战斗测试场景。`W/S` 推进/刹车，`A/D` 转向，鼠标瞄准/左键开火，`1–6` 选择武器，`Q` 护盾，`F` 隐身，`E` EMP，`R` HACK，`Tab` 切换 HACK 目标模块，`Shift` 短距跃迁，`Space` 撤离跃迁，`O/P/I` 切换光学/雷达/红外，`Esc` 返回菜单。`F1` 展开/收起测试面板，可重置状态和切换目标条件。

`Sensors & Stealth` 中，自机起始开启隐身，被八座联控炮台包围。推进会产生红外特征，先加速再冷态惯性滑行，从炮台间隙穿过 1,350 米突围边界。橙色圈表示炮台的红外探测范围。突围途中被发现后，即使重新隐身也不计入进度，需要退回中心 600 米安全区，恢复隐身、冷却后重新潜行离开。成功突围后，圈外主控舰的网络护盾解除；摧毁主控舰使所有炮台永久失效并解除其护盾，最后摧毁全部失效炮台完成任务。HUD 显示当前任务阶段，主控舰有 COMMAND 标记，停机炮台显示 OFFLINE。

跃迁需要连续 5 秒保持操作静默，自机下方显示充能进度。新按键、鼠标移动、点击、滚轮和持续推进、转向、开火都会打断并清零；松开启动用的 Space 不会打断。受到撞击、EMP 或离开任务要求的撤离区域也会中断。任务结束使用全屏大字、遮罩渐入和标题收束动画，按 Esc 返回主菜单。

滚轮缩放；`V` 切换跟随/自由视角。自由视角下按住右键或中键拖动，也可点击或拖动右下角小地图跳转视角；此时仍可左键远程瞄准开火。跟随视角缩放范围为 45%–160%，自由视角为 8%–160%。小地图保持固定比例，自机驶出初始区域后平移显示范围；显示自机、探测到的敌人、鱼雷和当前视野。屏幕外的探测目标显示方位箭头与距自机的距离。

BULLET 发射间隔为 0.06 秒；CANNON 间隔为 0.96 秒、弹速为 2,040 米/秒，使用粗线段弹体，并产生短促震屏和后坐力。PULSE 每次扣费发射五发，间隔 0.065 秒，每发增加热量、重新读取瞄准方向，可扫射；一轮后有明显的装填间隔。松开鼠标仍完成这一轮，切换武器或 EMP 会中断。按住左键时 BEAM 连续发射，射程 900 米，末端变细渐隐；伤害、能耗与热量按物理帧时间结算。MISSILE 燃料耗尽后保持速度滑行，随后渐隐失效。

TORPEDO 有效瞄准距离为 350–12,000 米，准心红色叉号表示距离不合法，不耗能也不进入冷却。近距离警戒圈只在准心进入 350 米范围时显示。鱼雷先沿垂直于目标方向冷发射弹出，弹体始终朝向目标，再转向瞄准点、点火加速。普通关卡装备速射鱼雷：发射间隔 1.6 秒，弹出速度 160 米/秒，点火延迟 0.35 秒，加速度 400 米/秒²，伤害 70，爆炸半径 100 米。`Torpedo Sniping` 装备重型鱼雷：发射间隔 3.8 秒，弹出速度 65 米/秒，点火延迟 0.7 秒，加速度 150 米/秒²，伤害 560，爆炸半径 800 米。两者巡航速度均为 1,000 米/秒；加速期间有尾焰和烟雾，巡航后停止产生烟雾，在命中或飞完设定距离时爆炸。重型爆炸带有持续火球、烟尘、碎片和双层冲击波，震屏随镜头到爆炸的距离衰减，任务完成后动画仍会播放。狙击关卡默认跟随视角并启用远程雷达，玩家按 `V` 手动切换自由视角，从 3,000 米防御圈外摧毁分别装备 BULLET、PULSE、MISSILE 的三座炮台。

左上角船体、电力、当前武器热量使用细分格条及数值显示；右侧一排六个武器图标支持点击选择，也可用 `1–6` 快捷键，当前武器高亮。SHIELD、STEALTH、HACK 用盾牌、隐身眼和芯片图标显示，亮色实心指示点表示开启或就绪，暗色空心点表示关闭，红色叉号表示离线；悬停可查看完整状态与快捷键，HACK 图标旁保留当前目标模块缩写。

Web 包：`mkdir -p build/web` 后运行 `godot --headless --path godot --export-release Web ../build/web/index.html`。用 `python3 -m http.server 8765 --directory build/web` 在本地启动，再访问 `http://localhost:8765/`。目标为桌面 Chrome/Firefox；需由 HTTP 服务器提供文件，不能直接打开 `index.html`。`build/` 不纳入版本控制。

当前版本覆盖战斗机制的代表性实现；原始企划保存在 [docs/design.md](docs/design.md)，八张设计图仍位于 docs/。采矿、交易、星门经济和完整装配系统以原始企划为设计资料。开发入口、验证命令和改动约定见 [AGENTS.md](AGENTS.md)。
